# 要件定義書 — 異世界ホストクラブ・タイクーン（仮題）

作成日: 2026-11-08
ステータス: ドラフト v0.1（ヒアリング結果ベース）

---

## 1. コンセプト

異世界に転生した主人公がホストクラブを開店し、酒を運び・接客し・稼いだ金で店と従業員を拡張していく **Idle Arcade × Idle Tycoon** 型のライフシミュレーション。

- ジャンル: ハイパーカジュアル系タイクーン（Idle Arcade + Idle Tycoon）
- 想定プレイ時間: 約12時間（全店舗解放＋図鑑コンプまで）
- 対象: 自分・友人（個人利用）
- 対応環境: PCデスクトップ（macOS / Windows）
- 容量目標: **インストーラー 10MB 以下**、画像アセットはコード描画中心

## 2. 技術構成

| 項目 | 選定 | 理由 |
|---|---|---|
| ゲーム本体 | HTML5 Canvas + TypeScript（フレームワーク不使用、自前ゲームループ） | 最小容量・依存ゼロ |
| デスクトップ化 | Tauri v2 | 数MBの実行ファイル。Electronの1/20以下 |
| ビルド | Vite | 高速・小さいバンドル |
| 描画 | ドット絵風（16×16基準、Canvasのピクセルスケーリング） | 画像ファイル不要、後からスプライト差替可 |
| セーブ | ローカルJSON（Tauri fs / localStorage フォールバック） | オフライン完結 |
| 効果音 | Web Audio API で合成（任意・後回し） | 音声ファイル不要 |
| リポジトリ | GitHub Public | CI でビルド配布（GitHub Releases） |

ブラウザ（`vite dev`）でも動作させ、開発中はブラウザで確認、配布は Tauri ビルド。

## 3. コア機能（MVP: 最初の5機能）

1. **移動**: WASD / 矢印キー ＋ マウスドラッグ仮想スティックの両対応
2. **自動回収**: 酒蔵（ストック台）に近づくとボトルを自動で手に積む（上限あり）
3. **自動販売**: 客が着席しているテーブルに近づくとボトルを自動で提供→売上発生
4. **お金**: 画面上部に所持金表示、売上は演出付きで加算
5. **拡張**: 金でテーブル追加・酒蔵アップグレード・従業員（ホスト）雇用

### 3.1 ゲームループ（1店舗内）

```
客が来店 → 空席に着席 → 酒を待つ
主人公/ホストが酒蔵でボトル回収 → テーブルへ運搬 → 売上
売上で [テーブル増設 / 酒蔵強化 / ホスト雇用(ガチャ) / 店舗解放]
```

## 4. 従業員（ホスト）ガチャ

### 4.1 レア度

| レア度 | 排出率 | 収益倍率 | 移動速度 | 運搬数 |
|---|---|---|---|---|
| N | 60% | ×1.0 | 1.0 | 2 |
| R | 28% | ×1.5 | 1.2 | 3 |
| SR | 9.5% | ×2.5 | 1.4 | 4 |
| SSR | 2% | ×5.0 | 1.6 | 6 |
| **シークレット（UR）** | **0.5%** | ×12.0 | 2.0 | 10 |

- シークレットは図鑑上も「???」表示で、入手するまで存在が明かされない
- シークレットは **種族「神」の2キャラのみ**

### 4.2 種族（例: 各レア度に2〜3名）

| 種族 | 特技（パッシブ） |
|---|---|
| 人間 | 均等。欠点なし |
| エルフ | 移動速度 +20% |
| ドワーフ | 運搬数 +2 |
| 獣人 | 客の待ち時間耐性 +（客が帰りにくい） |
| 魔族 | 売上 +15%、ただし客の来店間隔が少し長い |
| ドラゴン | SSR限定。全ステータス高水準 |
| **神** | **シークレット限定・2キャラ。** 在籍中は店全体の売上 +30%、客の来店間隔 −20% |

### 4.3 被り・天井

- 同一キャラ被り → **限界突破**（最大+5、1段階ごとに収益倍率 +10%）
- **天井**: 50連で SSR 以上確定（カウンターは SSR/UR 排出時リセット）。シークレットに天井はなし
- ガチャ通貨: ゲーム内マネー（課金なし）。単発 / 10連

### 4.4 図鑑

- 全ホストの一覧、未入手はシルエット表示
- レア度別コンプで永続ボーナス（例: N全種コンプ→全売上+5%）

## 5. 進行構成（店舗の段階解放）

| # | 店舗 | 解放条件 | 到達目安 |
|---|---|---|---|
| 1 | 場末の酒場「はじまりの灯」 | 初期 | 0h |
| 2 | 街のホストクラブ | 累計売上 5万G | 1.5h |
| 3 | 貴族街の高級店 | 累計売上 50万G | 4h |
| 4 | 王都一番店 | 累計売上 500万G | 7h |
| 5 | 魔王城ラウンジ | 累計売上 5,000万G | 10h |
| 6 | （余裕があれば）天界クラブ | 図鑑コンプ | 12h |

- 店舗は切り替え式。解放済みの店舗は**裏で自動稼働**し、ホストの数に応じて収益を出し続ける（ゲーム起動中のみ）
- **放置収益（オフライン収益）はなし**（ヒアリング確定）

## 6. 画面構成

1. **タイトル**: New Game / Continue
2. **店舗（メイン）**: 見下ろし視点、酒蔵・テーブル・入口・レジ。HUDに所持金・現在店舗名
3. **ショップ**: テーブル増設 / 酒蔵Lv / 主人公強化（速度・運搬数）
4. **ガチャ**: 単発・10連、演出、天井カウンター
5. **図鑑**: ホスト一覧、限界突破段階
6. **店舗マップ**: 解放済み店舗の切替と次店舗の解放条件

## 7. 非機能要件

- 起動 2秒以内、常時 60fps（Canvas 2D、オブジェクト数 < 200）
- 自動セーブ（30秒ごと＋終了時）、セーブ破損時は直前バックアップから復旧
- ウィンドウサイズ可変（最小 960×600）、ピクセルスケール整数倍
- 外部通信なし
