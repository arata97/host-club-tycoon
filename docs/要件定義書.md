# 要件定義書 — 転生してもホストだった件

作成日: 2026-11-08
更新日: 2026-11-08
ステータス: ドラフト v0.3（§10 経営サイクルを追加。§3.1・§3.3・§5 の一部は §10 で上書き）

---

## 1. コンセプト

異世界に転生した主人公がホストクラブを開店し、酒を運び・接客し・稼いだ金で店と従業員を拡張していく **Idle Arcade × Idle Tycoon** 型のライフシミュレーション。

- ジャンル: ハイパーカジュアル系タイクーン（Idle Arcade + Idle Tycoon）
- 想定プレイ時間: 約12時間（全店舗解放＋図鑑コンプまで）
- 対象: 自分・友人（個人利用）
- 対応環境: PCデスクトップ（macOS / Windows）
- 容量目標: **インストーラー 10MB 以下**、画像アセットはコード描画中心

## 2. 技術構成

| 項目 | 選定 | 理由 |
|---|---|---|
| ゲーム本体 | HTML5 Canvas + TypeScript（フレームワーク不使用、自前ゲームループ） | 最小容量・依存ゼロ |
| デスクトップ化 | Tauri v2 | 数MBの実行ファイル。Electronの1/20以下 |
| ビルド | Vite | 高速・小さいバンドル |
| 描画 | ドット絵風（16×16基準、Canvasのピクセルスケーリング） | 画像ファイル不要、後からスプライト差替可 |
| セーブ | ローカルJSON（Tauri fs / localStorage フォールバック） | オフライン完結 |
| 効果音 | Web Audio API で合成（任意・後回し） | 音声ファイル不要 |
| リポジトリ | GitHub Public | CI でビルド配布（GitHub Releases） |

ブラウザ（`vite dev`）でも動作させ、開発中はブラウザで確認、配布は Tauri ビルド。

## 3. コア機能（MVP: 最初の5機能）

1. **移動**: WASD / 矢印キー ＋ マウスドラッグ仮想スティックの両対応
2. **自動回収**: 酒蔵（ストック台）に近づくとボトルを自動で手に積む（上限あり）
3. **自動販売**: 客が着席しているテーブルに近づくとボトルを自動で提供→売上発生
4. **お金**: 画面上部に所持金表示、売上は演出付きで加算
5. **拡張**: 金でテーブル追加・酒蔵アップグレード・従業員（ホスト）雇用

### 3.1 ゲームループ（1店舗内）

```
客が来店 → 空席に着席 → 酒を注文
空いているホストが卓に着く（接客開始）
主人公/内勤が酒蔵でボトル回収 → テーブルへ運搬 → 客が飲む → 支払い
ホストが着いていれば客は「おかわり」を追加注文（繰り返し）→ 退店
売上で [テーブル増設 / 酒蔵強化 / 内勤雇用・教育 / ホスト獲得(ガチャ) / 店舗解放]
```

### 3.1.1 従業員は「内勤」と「ホスト」の2系統

実際のホストクラブと同じく、**酒を運ぶ内勤（黒服）** と **卓に着いて接客するホスト** を分ける。

| | 内勤（黒服） | ホスト |
|---|---|---|
| 役割 | 酒蔵→客席へボトルを運搬 | 客のいる卓に自動で着き、客が帰るまで接客 |
| 入手 | ショップで雇用（人数） | ガチャ（フェーズ2まではショップでスカウト） |
| 成長 | 「内勤教育Lv」で全員の速度・運搬数が上がる | レア度・限界突破 |
| 接客効果 | なし | ①卓の売上にレア度倍率 ②客が追加注文（おかわり） ③客の我慢ゲージ減少が半分 ④高グレードを注文しやすい |
| 待機 | 酒蔵前 | 右端の待機席 |

- **主人公（店長）** は運搬も接客もできる。客席の前に立つと提供＋接客（N ホスト相当: 売上×1.0、おかわり+1杯）。従業員が増えるほど主人公の手が空く設計
- ホストはボトルを運ばない。内勤は接客しない

### 3.3 客と VIP 客

- 通常客: 一定間隔で来店し、空席に着席。提供可能な商品からランダムに注文し、待ち時間が限界を超えると帰る
- **VIP 客（シンプル版）**: 低確率（来店の約5%）で貴族・王女などの VIP が来店
  - 提供可能な中で **最高グレードの商品** を注文し、**単価 ×3**
  - 来店時に専用の演出（入口にスポットライト／金色のエフェクト）
  - ホストの指名やチップは MVP では実装しない（将来拡張候補）

## 4. 従業員（ホスト）ガチャ

### 4.1 レア度とステータス

ホストは卓に着いて接客する（§3.1.1）。ステータスはすべて「着いている卓」に効く。

| レア度 | 売上倍率 | おかわり杯数 | 注文グレード補正 | 移動速度 | 人数 |
|---|---|---|---|---|---|
| N | ×1.0 | +1 | 0 | 1.0 | 7 |
| R | ×1.5 | +2 | 1 | 1.2 | 5 |
| SR | ×2.5 | +3 | 2 | 1.4 | 4 |
| SSR | ×5.0 | +4 | 3 | 1.6 | 2 |
| **シークレット（UR）** | ×12.0 | +6 | 4 | 2.0 | 2 |

- おかわり: 客は初回の1杯に加えてこの杯数を追加注文する（1杯ごとに支払い）
- 注文グレード補正: 大きいほど高グレードの酒を注文しやすくなる（提供可能グレード内で）

総数 **20人**。シークレットは図鑑上も「???」表示で、入手するまで存在が明かされない。シークレットは **種族「神」の2キャラのみ**。

### 4.2 店舗ごとの排出制限と排出率

ガチャの排出プールは **現在の店舗レベルで決まる**。

- 新しい店舗を解放するたびに新キャラがプールに **追加** される（累積式。旧店舗のキャラも引き続き排出され、限界突破を狙える）
- SR は店舗2から、SSR は店舗3からプールに入る
- **UR（神）は店舗1から排出対象**だが超低確率。店舗が進むごとに排出率が上がり、店舗5で適正値（0.5%）に達する

| 店舗 | N | R | SR | SSR | UR | 天井（50連） |
|---|---:|---:|---:|---:|---:|---|
| 1 場末の酒場 | 74.99% | 25% | — | — | **0.01%** | R 確定 |
| 2 街のホストクラブ | 64.95% | 28% | 7% | — | **0.05%** | SR 確定 |
| 3 貴族街の高級店 | 60.9% | 28% | 9.5% | 1.5% | **0.1%** | SSR 確定 |
| 4 王都一番店 | 60.25% | 28% | 9.5% | 2% | **0.25%** | SSR 確定 |
| 5 魔王城ラウンジ以降 | 60% | 28% | 9.5% | 2% | **0.5%** | SSR 確定 |

- 天井カウンターは「天井対象レア度以上」の排出時にリセット。UR に天井はなし
- ガチャ価格は店舗ごとに ×10（§4.5）

### 4.3.1 出勤制

### 4.4 被り・図鑑

- 同一キャラ被り → **限界突破**（最大+5、1段階ごとに売上倍率 +10%）
- 限界突破 MAX で被った場合は **単発価格の半額を返金**
- 図鑑: 全ホストの一覧、未入手はシルエット表示＋出現店舗、限界突破段階（★）、種族パッシブ、出勤状態を表示
- **UR は入手するまで図鑑に枠ごと表示しない**（所持数も「/18」表示。入手で「/20」になり存在が明かされる）
- レア度別コンプで永続ボーナス（全売上に加算）: N +5% / R +10% / SR +15% / SSR +20% / UR +30%。全コンプで店舗6「天界クラブ」解放（フェーズ3）

### 4.5 ガチャ価格

ゲーム内マネー（課金なし）。単発 / 10連。店舗ごとに価格 ×10 し、常に「少し頑張れば引ける」感覚を維持する。

## 6. 画面構成

1. **タイトル**: New Game / Continue
2. **店舗（メイン）**: 見下ろし視点、酒蔵・テーブル・入口・レジ。HUDに所持金・現在店舗名
3. **ショップ**（B）: テーブル増設 / 酒蔵Lv / 主人公強化（速度・運搬数） / 内勤の雇用・教育
4. **ガチャ**（G）: 単発・10連、結果カード（NEW／限界突破／返金）、SSR・UR 演出、天井カウンター、現在店舗の排出率表示（UR は「???」表記）
5. **図鑑**（Z）: ホスト一覧、限界突破段階、コンプボーナス、出勤状態
- パネルは同時に1つだけ開き、開いている間は主人公の移動を止める（シミュレーションは進む）。Esc で閉じる
6. **店舗マップ**: 解放済み店舗の切替と次店舗の解放条件

## 7. 非機能要件

- 起動 2秒以内、常時 60fps（Canvas 2D、オブジェクト数 < 200）
- 自動セーブ（30秒ごと＋終了時）、セーブ破損時は直前バックアップから復旧
- ウィンドウサイズ可変（最小 960×600）、ピクセルスケール整数倍
- 外部通信なし

## 10. 経営サイクル（v0.3 追加）

フェーズ2までの「放置系アーケード」に、**営業日・支出・借金・給与・つけ回し・同伴／アフター**を加え、
ホストクラブ経営シミュレーションとしての奥行きを持たせる。本章は §3.1 のゲームループと §3.3 の客仕様を上書きする。

### 10.1 時間

| 項目 | 値 |
|---|---|
| 営業時間 | 20:00〜24:00（4時間） |
| 時間スケール | **ゲーム内1分＝リアル1秒**。1営業日＝リアル4分 |
| 客の滞在 | 60〜120分（リアル1〜2分）。予算が尽きるか滞在上限で退店 |
| 注文間隔 | 1杯 10〜20分。ホストが着いていれば滞在中ずっと注文が続く |
| 全クリア目安 | 約150営業日（経営フェーズ込みで約12時間） |

時間帯で客層が変わる:

| 時間帯 | 客層 |
|---|---|
| 20:00〜21:00 | 一見客が多い。予算低め、滞在短め |
| 21:00〜23:00 | 通常。指名客・VIP が混ざる |
| 23:00〜24:00 | 太客・VIP の割合が上がる。予算大、おかわり多め |

### 10.2 1日の流れ

```
[開店前：経営フェーズ（時間停止）]
  日報の確認 → 支払い（給与・家賃・利息・返済） → ショップ／ガチャ
  → 出勤ホストの選択 → つけ回し方針の選択 → 同伴の確定 → 「開店」
        ↓
[営業中 20:00〜24:00（リアルタイム・アクション）]
  客の来店 → つけ回し（自動／手動上書き） → 回収・運搬・提供 → おかわり → 会計・退店
        ↓
[閉店・精算]
  売上／原価／給与／家賃／利息 → 純利益、現金・借金残高
  ホストごとの成績（売上・指名数・疲労）
  → アフターの選択 → 翌日の同伴オファー → 開店前へ
```

- 営業中は時間が止まらない。ショップ・ガチャは開店前のみ（営業中は図鑑の閲覧のみ可）
- 開店前の経営フェーズは時間停止なので、じっくり考えられる

### 10.3 支出

閉店時にまとめて精算する。売上は営業中にリアルタイムで現金に入り、支出は閉店時に引かれる。

| 項目 | 内容 | 目安（店舗1） |
|---|---|---|
| 家賃 | 店舗ごとに固定の日額 | 20,000G/日 |
| 仕入れ（原価） | 提供したボトルごとに売価の **30%** | 売上に比例 |
| 内勤給与 | 固定日給 × 人数（教育Lvで微増） | 8,000G/人 |
| ホスト給与 | §10.4 | 売上に比例 |
| 借金利息 | §10.5 | 借入残高 × 日利 |

純利益 ＝ 売上 − 原価 − 給与 − 家賃 − 利息。日報に内訳を表示する。

### 10.4 ホストの給与（歩合制＋最低保証）

- ホストは **自分が着いた卓の売上** の一定率を受け取る。レア度が高いほど率が高い

| レア度 | 歩合率 | 最低保証（日給） |
|---|---|---|
| N | 40% | 5,000G |
| R | 45% | 10,000G |
| SR | 50% | 30,000G |
| SSR | 55% | 100,000G |
| UR | 60% | 300,000G |

- その日の歩合が最低保証を下回れば最低保証を支払う。**出勤させたホストにだけ**発生（控えは無給）
- 最低保証は店舗レベルに応じて ×1 / ×3 / ×10 / ×30 / ×100 でスケール
- → 「SSR を出勤させれば必ず得」ではない。客単価の低い序盤に高レアを出すと赤字になり得る（攻略性）

### 10.5 借金・倒産・再転生

- **開業資金として 1,000,000G を借りた状態でスタート**（手元現金 200,000G）
- 日利 **0.3%**（1,000,000G なら 3,000G/日）。利息は閉店精算で自動加算
- 返済は開店前の「財務」画面で任意額。追加借入も可能（借金残高の上限 ＝ 開業資金 100万G ＋ max(50万G, 直近7日の売上合計 × 3)）
- 店舗解放時は解放費用の借入を提案する（借りずに現金で払ってもよい）
- **倒産**: 閉店精算で現金がマイナスになり、翌営業日の開店前までに解消できない状態が **3日続く** と倒産
- **再転生（周回）**: 倒産すると異世界に再転生し、最初から。引き継ぐもの／失うもの:

| 引き継ぐ | 失う |
|---|---|
| 図鑑（所持ホスト・限界突破） | 現金・借金 |
| 転生回数に応じた永続ボーナス（1回ごとに開始資金 +10%、家賃 −5%） | 店舗・設備・内勤・教育Lv |
| 天井カウンター | 太客・好感度 |

### 10.6 客の深掘り

客は以下を持つ:

| 属性 | 内容 |
|---|---|
| タイプ | 冒険者／商人／貴族／魔導士／王族 の5種。時間帯と店舗で出現率が変わる |
| 好みの種族 | タイプごとに相性の良い種族が2つ。相性良＝売上 +30%・指名しやすい、相性悪＝売上 −20% |
| 予算 | 来店時に決まる。注文のたびに減り、尽きると帰る。タイプ・時間帯・好感度で増減 |
| 我慢ゲージ | 既存。注文待ちで減る。ホストが着いていると減りが遅い |
| 指名 | 太客は特定ホストを指名して来店。指名ホストが着くと売上 +50%。他のホストだと通常、誰も着かないと我慢ゲージが倍速で減る |
| 好感度（太客のみ） | 0〜100。同伴・アフター・指名ホストの接客で上がり、待たせる・指名不在で下がる。高いほど来店頻度と予算が上がる。0 で店を離れる |

- **初回指名**: 一見客が「相性の良いホスト」に着かれ、待たされずに帰ると、一定確率でそのホストの **太客** になる（次回から指名で来店）
- 太客はホストごとのリスト（最大5人）として保持。図鑑のホスト詳細に表示

### 10.7 ホストの疲労と出勤選択

- 各ホストに **スタミナ 0〜100**。卓に着いている間 1/分で減少、アフターで −40、休み（控え）の日に +60、出勤日の開店時に +30
- スタミナが低いと接客効果が落ちる: 売上倍率 × (0.5 + 0.5 × スタミナ/100)。0 では着席できず待機席で休む
- **出勤選択**: 開店前に、所持ホストから出勤メンバーを選ぶ（枠＝卓数）。従来の「レア度順に自動」は初期値とし、手動で入れ替え可
- → エースを連日使うと疲弊する。ローテーションと休養日の管理が攻略の核

### 10.8 つけ回し（どのホストをどの卓に着けるか）

**方針で自動＋営業中に手動で上書き**。

開店前に方針を1つ選ぶ（内勤が実行）:

| 方針 | 動作 |
|---|---|
| 相性優先 | 客のタイプと相性の良いホストを優先 |
| 指名優先 | 指名客を最優先で指名ホストに。一見客は手の空いた者 |
| 均等ローテ | 疲労が少ない順に回す |
| エース集中 | レア度の高い順に着ける（高単価狙い、疲労は早い） |

営業中の手動上書き:
- 店長（主人公）が卓に近づくと、着いているホスト名と客タイプが表示される
- **E キー**（または卓クリック）で出勤ホスト一覧がポップアップ。選ぶと入れ替わる（疲労・相性・指名の有無を一覧で見せる）
- 店長自身が卓に立つと「ヘルプ」として接客（従来どおり N 相当）

### 10.9 同伴・アフター

**同伴**（開店前に確定、効果は当日）
- 閉店精算の後、太客（好感度 50 以上）からホスト宛てに同伴の誘いが来る（ホストごと最大2件）
- 受けると: 翌日 20:00 開店と同時にその客が来店確定、**同伴料**（10,000G × 店舗倍率）が売上に加算、その客の予算 +30%、ホストのスタミナ −10（開店前から働く）
- 断ると: 好感度 −5
- 1ホスト1日1件まで

**アフター**（閉店時に選択、効果は翌日以降）
- 閉店時、その日に来店した指名客からアフターの誘いが来る
- 受けると: 好感度 +20、その客の来店頻度 UP、翌来店時の予算 +50%、ホストのスタミナ **−40**
- 断ると: 好感度 −5
- 1ホスト1日1件まで。連日のアフターはスタミナ管理を圧迫する（攻略）
