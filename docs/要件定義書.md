# 要件定義書 — 転生してもホストだった件

作成日: 2026-11-08
更新日: 2026-11-08
ステータス: ドラフト v0.2（未決事項の大半を確定）

---

## 1. コンセプト

異世界に転生した主人公がホストクラブを開店し、酒を運び・接客し・稼いだ金で店と従業員を拡張していく **Idle Arcade × Idle Tycoon** 型のライフシミュレーション。

- ジャンル: ハイパーカジュアル系タイクーン（Idle Arcade + Idle Tycoon）
- 想定プレイ時間: 約12時間（全店舗解放＋図鑑コンプまで）
- 対象: 自分・友人（個人利用）
- 対応環境: PCデスクトップ（macOS / Windows）
- 容量目標: **インストーラー 10MB 以下**、画像アセットはコード描画中心

## 2. 技術構成

| 項目 | 選定 | 理由 |
|---|---|---|
| ゲーム本体 | HTML5 Canvas + TypeScript（フレームワーク不使用、自前ゲームループ） | 最小容量・依存ゼロ |
| デスクトップ化 | Tauri v2 | 数MBの実行ファイル。Electronの1/20以下 |
| ビルド | Vite | 高速・小さいバンドル |
| 描画 | ドット絵風（16×16基準、Canvasのピクセルスケーリング） | 画像ファイル不要、後からスプライト差替可 |
| セーブ | ローカルJSON（Tauri fs / localStorage フォールバック） | オフライン完結 |
| 効果音 | Web Audio API で合成（任意・後回し） | 音声ファイル不要 |
| リポジトリ | GitHub Public | CI でビルド配布（GitHub Releases） |

ブラウザ（`vite dev`）でも動作させ、開発中はブラウザで確認、配布は Tauri ビルド。

## 3. コア機能（MVP: 最初の5機能）

1. **移動**: WASD / 矢印キー ＋ マウスドラッグ仮想スティックの両対応
2. **自動回収**: 酒蔵（ストック台）に近づくとボトルを自動で手に積む（上限あり）
3. **自動販売**: 客が着席しているテーブルに近づくとボトルを自動で提供→売上発生
4. **お金**: 画面上部に所持金表示、売上は演出付きで加算
5. **拡張**: 金でテーブル追加・酒蔵アップグレード・従業員（ホスト）雇用

### 3.1 ゲームループ（1店舗内）

```
客が来店 → 空席に着席 → 酒を注文
空いているホストが卓に着く（接客開始）
主人公/内勤が酒蔵でボトル回収 → テーブルへ運搬 → 客が飲む → 支払い
ホストが着いていれば客は「おかわり」を追加注文（繰り返し）→ 退店
売上で [テーブル増設 / 酒蔵強化 / 内勤雇用・教育 / ホスト獲得(ガチャ) / 店舗解放]
```

### 3.1.1 従業員は「内勤」と「ホスト」の2系統

実際のホストクラブと同じく、**酒を運ぶ内勤（黒服）** と **卓に着いて接客するホスト** を分ける。

| | 内勤（黒服） | ホスト |
|---|---|---|
| 役割 | 酒蔵→客席へボトルを運搬 | 客のいる卓に自動で着き、客が帰るまで接客 |
| 入手 | ショップで雇用（人数） | ガチャ（フェーズ2まではショップでスカウト） |
| 成長 | 「内勤教育Lv」で全員の速度・運搬数が上がる | レア度・限界突破 |
| 接客効果 | なし | ①卓の売上にレア度倍率 ②客が追加注文（おかわり） ③客の我慢ゲージ減少が半分 ④高グレードを注文しやすい |
| 待機 | 酒蔵前 | 右端の待機席 |

- **主人公（店長）** は運搬も接客もできる。客席の前に立つと提供＋接客（N ホスト相当: 売上×1.0、おかわり+1杯）。従業員が増えるほど主人公の手が空く設計
- ホストはボトルを運ばない。内勤は接客しない

### 3.3 客と VIP 客

- 通常客: 一定間隔で来店し、空席に着席。提供可能な商品からランダムに注文し、待ち時間が限界を超えると帰る
- **VIP 客（シンプル版）**: 低確率（来店の約5%）で貴族・王女などの VIP が来店
  - 提供可能な中で **最高グレードの商品** を注文し、**単価 ×3**
  - 来店時に専用の演出（入口にスポットライト／金色のエフェクト）
  - ホストの指名やチップは MVP では実装しない（将来拡張候補）

## 4. 従業員（ホスト）ガチャ

### 4.1 レア度とステータス

ホストは卓に着いて接客する（§3.1.1）。ステータスはすべて「着いている卓」に効く。

| レア度 | 売上倍率 | おかわり杯数 | 注文グレード補正 | 移動速度 | 人数 |
|---|---|---|---|---|---|
| N | ×1.0 | +1 | 0 | 1.0 | 7 |
| R | ×1.5 | +2 | 1 | 1.2 | 5 |
| SR | ×2.5 | +3 | 2 | 1.4 | 4 |
| SSR | ×5.0 | +4 | 3 | 1.6 | 2 |
| **シークレット（UR）** | ×12.0 | +6 | 4 | 2.0 | 2 |

- おかわり: 客は初回の1杯に加えてこの杯数を追加注文する（1杯ごとに支払い）
- 注文グレード補正: 大きいほど高グレードの酒を注文しやすくなる（提供可能グレード内で）

総数 **20人**。シークレットは図鑑上も「???」表示で、入手するまで存在が明かされない。シークレットは **種族「神」の2キャラのみ**。

### 4.2 店舗ごとの排出制限と排出率

ガチャの排出プールは **現在の店舗レベルで決まる**。

- 新しい店舗を解放するたびに新キャラがプールに **追加** される（累積式。旧店舗のキャラも引き続き排出され、限界突破を狙える）
- SR は店舗2から、SSR は店舗3からプールに入る
- **UR（神）は店舗1から排出対象**だが超低確率。店舗が進むごとに排出率が上がり、店舗5で適正値（0.5%）に達する

| 店舗 | N | R | SR | SSR | UR | 天井（50連） |
|---|---:|---:|---:|---:|---:|---|
| 1 場末の酒場 | 74.99% | 25% | — | — | **0.01%** | R 確定 |
| 2 街のホストクラブ | 64.95% | 28% | 7% | — | **0.05%** | SR 確定 |
| 3 貴族街の高級店 | 60.9% | 28% | 9.5% | 1.5% | **0.1%** | SSR 確定 |
| 4 王都一番店 | 60.25% | 28% | 9.5% | 2% | **0.25%** | SSR 確定 |
| 5 魔王城ラウンジ以降 | 60% | 28% | 9.5% | 2% | **0.5%** | SSR 確定 |

- 天井カウンターは「天井対象レア度以上」の排出時にリセット。UR に天井はなし
- ガチャ価格は店舗ごとに ×10（§4.5）

### 4.3.1 出勤制

### 4.4 被り・図鑑

- 同一キャラ被り → **限界突破**（最大+5、1段階ごとに売上倍率 +10%）
- 限界突破 MAX で被った場合は **単発価格の半額を返金**
- 図鑑: 全ホストの一覧、未入手はシルエット表示＋出現店舗、限界突破段階（★）、種族パッシブ、出勤状態を表示
- **UR は入手するまで図鑑に枠ごと表示しない**（所持数も「/18」表示。入手で「/20」になり存在が明かされる）
- レア度別コンプで永続ボーナス（全売上に加算）: N +5% / R +10% / SR +15% / SSR +20% / UR +30%。全コンプで店舗6「天界クラブ」解放（フェーズ3）

### 4.5 ガチャ価格

ゲーム内マネー（課金なし）。単発 / 10連。店舗ごとに価格 ×10 し、常に「少し頑張れば引ける」感覚を維持する。

## 6. 画面構成

1. **タイトル**: New Game / Continue
2. **店舗（メイン）**: 見下ろし視点、酒蔵・テーブル・入口・レジ。HUDに所持金・現在店舗名
3. **ショップ**（B）: テーブル増設 / 酒蔵Lv / 主人公強化（速度・運搬数） / 内勤の雇用・教育
4. **ガチャ**（G）: 単発・10連、結果カード（NEW／限界突破／返金）、SSR・UR 演出、天井カウンター、現在店舗の排出率表示（UR は「???」表記）
5. **図鑑**（Z）: ホスト一覧、限界突破段階、コンプボーナス、出勤状態
- パネルは同時に1つだけ開き、開いている間は主人公の移動を止める（シミュレーションは進む）。Esc で閉じる
6. **店舗マップ**: 解放済み店舗の切替と次店舗の解放条件

## 7. 非機能要件

- 起動 2秒以内、常時 60fps（Canvas 2D、オブジェクト数 < 200）
- 自動セーブ（30秒ごと＋終了時）、セーブ破損時は直前バックアップから復旧
- ウィンドウサイズ可変（最小 960×600）、ピクセルスケール整数倍
- 外部通信なし
